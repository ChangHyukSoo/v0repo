# 파일 하나의 힘

Markdown은 문서의 구조와 내용에 집중하게 해줍니다. 파일은 가볍고, 어디서든 읽을 수 있습니다.

## 추천하는 폴더 구조

```text
content/
└── posts/
    ├── first-post.md
    └── markdown-guide.md
```

## 작은 규칙 만들기

제목과 설명, 날짜만 잘 관리해도 포스팅 목록은 충분히 유용해집니다.

| 필드 | 역할 |
| --- | --- |
| title | 화면에 표시할 제목 |
| date | 정렬과 날짜 표시 |
| tags | 탐색과 연관 글 연결 |
